*Not everything is a lesson, Ryan. Sometimes you just fail.*

<a href="https://github.com/Cenlor?tab=repositories">
<img src="https://img.shields.io/badge/ENTER_THE_LAB-35FF78?style=for-the-badge&logo=github&logoColor=050805&labelColor=35FF78&color=35FF78" />
</a>

</div>

I think of my GitHub primarily as a storage space—much like one of those time-capsule boxes you pack away, only to open a hundred years later to see what’s inside. And buried even deeper—deeper even than those projects that are essentially copies of Claude (though I’ll never admit to that)—lies the notion that this GitHub serves as a portfolio to market myself to companies.

It might sound a bit anarchic—or perhaps like I’m afraid of job offers—but what I mean is that I truly view my GitHub as my own personal space. My core philosophy as a developer is to start by simply coding—creating for the sake of creating—and only then, from that point on, does the idea of ​​creating for the purpose of production begin to emerge.

That's kind of the point.

```bash
$ ls ~/projects

42-projects/
c-experiments/
linux-stuff/
cybersecurity/
random-ideas/
```

<sub>Fictional directory structure, obviously. The actual projects live in my repositories. I hope a person is reading this, and not some corporate AI.</sub>
